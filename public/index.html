HanoMan FF API emulator

Vercel serverless — tiruan endpoint auth & userver HanoMan.sh

Endpoints

AuthGET|POST /api/xapp-ff
UserverGET|POST /api/connection/v1/ff

Parameter auth

user_keymember key, contoh FF_5C015B
gameopsional, default ff

Contoh request

curl "https://<app>.vercel.app/api/xapp-ff?user_key=FF_5C015B"
curl -X POST -d "user_key=FF_5C015B&game=ff" "https://<app>.vercel.app/api/xapp-ff"

Respons auth (MIRROR — byte-identik server asli)

{
  "status":  "OK",
  "crypt":   "tx-₹7#_-3%09*",
  "userver": "https://hanoman.cakamin.com/api/connection/v1/ff",
  "chunk":   1,
  "dev":     "HANOMAN-FF"
}

Auth via Vercel, download config tetap dari server ORI (userver asli). Mode STRICT_KEYS=1: validasi key di Vercel & userver diarahkan ke host ini.
